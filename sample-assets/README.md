# Modelo de muestra

`result.glb` es el modelo de prueba aportado por el autor del proyecto. Contiene una malla texturizada. `scripts/prepare_sample_model.py` genera el OBJ que Unity importa; el OBJ generado no se guarda en Git porque supera 100 MB. La textura y el MTL del proyecto Unity proceden de este GLB.

La licencia del recurso debe fijarse explícitamente antes de publicar el repositorio. No asumas que la licencia del código, cuando se elija, cubra automáticamente este modelo.
